02 / SCOPE

Manual RC platform

Autonomous navigation is intentionally outside this repository.

Included

RC PWM input, drivetrain, kicker, dribbler on Advanced, protected power, failsafe and calibration.

Separate work

Ball tracking, obstacle avoidance, navigation and autonomous decision-making.

Reference radio: FlySky FS-i6 / FS-i6X + FS-iA6B. The base firmware uses individual PWM receiver outputs so other compatible radios can be substituted.

04 / POWER

Battery builder

Calculate series/parallel pack values before selecting the cells and regulator.

POWER PATH

Protection first

Battery +→Fuse→Master switch→Motor rail
↳ Buck / BEC → controller + receiver + servo
  • Keep motor current off the MCU supply rail.
  • Place the fuse close to battery positive.
  • Size wire, connectors and driver for measured current.
  • TB6612-based builds documented here are 2S/3S only.
