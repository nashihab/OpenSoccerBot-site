# OpenSoccerBot Web

Interactive GitHub Pages site for [nashihab/OpenSoccerBot](https://github.com/nashihab/OpenSoccerBot).

This repository contains the documentation interface only. The hardware designs, firmware, BOM and engineering documents remain in the main OpenSoccerBot repository.

## What it does

- BASIC / ADVANCED build switching
- Interactive chassis visualization
- RC control and motor-response visualizer
- Mecanum mixing view
- Wiring explorer with local SVG schematics
- Battery series/parallel calculator
- Component explorer
- Firmware structure and source links
- Build sequence
